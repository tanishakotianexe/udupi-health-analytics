UDUPI ATLAS — STANDALONE HTML EDITION

Open index.html in Chrome or Edge. No Python, installation, API key, online map tiles, external JavaScript or CDN is needed.

Includes: facility dot map, point concentration map, taluk count map, grouped points, straight-line distance circles, bed-capacity bubbles, government/private comparison, facility-care level map, and a year-by-year district health report map. Use the year slider and Play button; choose “History map · by year” in the map menu to see the district shade change.

The login screen is a demo welcome screen only, not secure account authentication. Do not enter a real password.

Bed capacity and ownership details were added from the table supplied with the project and matched to mapped locations by name where possible. Unmatched locations are not assumed to have zero beds. Verify the facility list and coordinates before formal use. Historical HMIS values are district-wide, not taluk-level; the history map colours the whole district and does not invent local differences.

PHC = Primary Health Centre; CHC = Community Health Centre; UPHC = Urban Primary Health Centre. Distance circles are straight-line approximations, not road travel time.
